# Design Tokens

## Title order
- h1: Page title only
- h2: Major section title
- h3: Subsection title

## Section spacing
- Page vertical padding: `xl`
- Section gap: `lg`
- Stack gap: `md`

## Card padding
- Default: `lg`
- Dense: `md`

## Status display
- Use `Badge` with `variant="light"` for status labels

## Color scheme
- Default is light; allow users to toggle light/dark
- Avoid hard-coded colors; prefer component variants and tokens
